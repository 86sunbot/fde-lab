## Findings

1. V3.1 preserved V2/V3 grounding behavior after changing chunking and retrieval.
2. The direct and paraphrased cases prove the supported-answer path still
   returns inspectable citations.
3. The unsupported case proves the evidence policy still abstains.
4. The persistent snapshot restores the 10-chunk index without rebuilding
   unchanged document embeddings.
5. The automated suite covers the eight V3 engineering principles without live
   OpenAI calls; the three-case evaluation verifies the real integration.

## Limitation

Docker execution was not validated because the local Docker CLI was unavailable.
The Compose YAML was parsed, and CI remains responsible for building the Docker
image. This is a functional smoke test, not a load, penetration, or statistical
RAG-quality benchmark.
