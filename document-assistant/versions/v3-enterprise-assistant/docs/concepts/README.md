# Concepts Learning Path

These guides explain the ideas before the implementation details. Read them in order if
AI and production engineering are new:

1. [AI Foundations](ai-foundations.md) — retrieval, embeddings, vectors, LLMs, RAG,
   grounding, citations, and evaluation.
2. [RAG Pipeline](rag-pipeline.md) — the exact indexing and question lifecycles used by
   this application.
3. [Production Engineering](production-engineering.md) — the controls wrapped around the
   preserved V2 capability in Version 3.

The concepts are deliberately tied to concrete project code. They do not attempt to cover
all of machine learning, web engineering, or distributed systems. Use the
[Glossary](../glossary.md) for quick definitions and [References](../references.md) for
authoritative external reading.
